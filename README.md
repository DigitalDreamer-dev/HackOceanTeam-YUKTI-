# 🌊 HackOceanTeam-YUKTI

HackOceanTeam-YUKTI is an interactive **Ocean Conservation** website built using **React + Vite**. It spreads awareness about marine life, plastic pollution, and encourages users to participate in ocean conservation activities.

## 🚀 Features
- 🌊 Ocean-themed Home Page
- 📖 Learn About Oceans
- 🧮 Plastic Footprint Calculator
- 🪸 Adopt a Coral Reef
- 🗺 Beach Cleanup Map
- 📊 Impact Dashboard
- 🤝 Volunteer Registration
- ✉ Newsletter Subscription
- ⭐ Ocean Guardian Pledge

## 🛠 Tech Stack
- React
- Vite
- React Router DOM
- Framer Motion
- React Icons
- React Leaflet
- CSS3

## ▶️ Installation

```bash
git clone <repository-url>
cd HackOceanTeam-YUKTI
npm install
npm run dev
```
